# 专利阅研 Patent Review Tool

专利阅研是一款面向专利代理师、企业知识产权工程师的 Windows 本地专利阅读辅助工具。它的核心目标是：在阅读本地 DOCX/PDF 专利稿件时，快速建立“说明书、权利要求书、附图、附图标记”之间的对应关系，并把审阅意见直接批注回修订版文件中。

当前 GitHub 正式发布版本：`v1.0.0`

## 下载与安装

进入发布页下载：

[https://github.com/talenlin/Patent-Review-Tool/releases/tag/v1.0.0](https://github.com/talenlin/Patent-Review-Tool/releases/tag/v1.0.0)

推荐下载方式：

如果只是快速试用，建议先下载免安装版，解压后直接运行即可。

## 支持的文件

- DOCX：优先支持中文专利初稿、专利申请文件、包含说明书附图的综合稿件。
- PDF：支持可检索 PDF。扫描版 PDF 需要依赖 OCR，识别效果取决于图片质量和 OCR 设置。

工具默认不会改动原文件。保存时会生成新文件，并在原文件名后自动增加 `-修订版`。

例如：

```text
一种电池.docx
一种电池-修订版.docx
```

## 基本使用流程

1. 打开工具。
2. 选择本地 DOCX 或 PDF 专利文件。
3. 在“文档结构确认”页面检查各阅读区段是否识别正确。
4. 确认后进入阅读界面。
5. 在右侧“批注与关联”区域确认“标号-特征”映射。
6. 点击“确认并应用映射”，工具会在附图区域生成浮动标记。
7. 阅读正文时选中文本，在右侧填写批注内容并添加批注。
8. 完成审阅后点击“保存修订版”。

## 文档结构确认

不同专利文本的模板顺序可能不同，例如“说明书摘要、摘要附图、权利要求书、说明书、说明书附图”的顺序不一定固定。

工具会根据页首、标题和正文特征尝试识别：

- 说明书摘要
- 权利要求书
- 说明书
- 说明书附图

如果识别不准，可以在确认页面手动调整对应区段。确认后再进入阅读，可以减少后续图文关联错误。

## 图文关联

工具会优先从说明书中的“附图标记”段落提取标号和特征名称；如果没有明确的附图标记段落，则会从全文上下文中提取候选。

确认映射时：

- 每个标号只显示一次。
- 默认选中出现频率更高、置信度更高的特征名称。
- 如果一个标号有多个候选名称，可以点击下拉框手动选择。
- 可以删除错误标号。
- 可以通过“自定义补充”手动增加标号。

确认后，工具会按最终映射表在正文和附图之间建立关联。

## 附图浮动标记

附图区域会显示识别到的标号对应特征，例如 `外壳 1`、`通孔 12`。

可用操作：

- 拖动浮动标记，避免遮挡附图细节。
- 点击标记上的关闭按钮，隐藏单个错误标记。
- 双击附图，可打开独立查看窗口并放大缩小。
- 点击正文或浮动标记，可辅助定位对应特征。

工具默认不把浮动标记写入原文档；它们主要用于阅读辅助。

## OCR 设置

默认使用本地 OCR。也可以在顶部 OCR 入口中切换云 OCR。

当前支持：

- 本机 OCR
- OCR.Space
- Google Cloud Vision
- PaddleOCR
- 自定义 OCR 接口

云 OCR 需要用户自行填写 API Key 或服务地址。工具会在设置弹窗中提供对应 API 获取入口。

隐私承诺：

- 正文、权利要求、批注内容、原始文件不会上传。
- 启用云 OCR 时，仅上传附图图片用于识别图中标号。
- API Key 保存在本机。

## 添加批注

进入审阅模式后：

1. 在正文阅读区选中需要批注的文字。
2. 右侧会锁定当前选区。
3. 选择批注类型和程度。
4. 填写批注人和批注内容。
5. 点击“添加批注”。

保存修订版后，DOCX 批注会以 WPS/Word 可查看的原生批注形式写入文件。

常见批注类型包括：

- 图文不一致
- 缺乏支持
- 表述不清楚
- 缺少数据支持
- 其他审阅意见

## LLM 专利辅助审查

顶部“LLM 审查”入口提供四个可单独勾选的模块：

- 技术理解与技术缺陷
- 清楚性、支持性及形式缺陷
- 对比文件的新颖性与创造性
- 确权与维权稳定性

首次使用时，需要选择 LLM 服务商并填写自己的 API Key。当前提供 OpenAI、DeepSeek、通义千问、Kimi 和自定义 OpenAI 兼容接口预设。点击“连接获取”后，工具会使用当前密钥读取该账号可用的模型，并以下拉菜单供用户选择；如果服务商不支持模型列表接口，仍可手工填写模型 ID。不同服务商的 API Key 分开保存，不会互相共享。

审查流程：

1. 填写或确认技术领域。工具同时读取说明书“技术领域”段落；两者差异明显时会要求人工选择。
2. 勾选本次需要的审查模块。
3. 明确本次发送范围：仅权利要求书、专利全文，或专利全文加对比文件。
4. 新颖性/创造性可由“上传对比文件”或“联网检索”任意一种方式启动；两者同时启用时共同进入候选池。
5. 如需联网检索，先由 LLM 生成检索方案，人工修改并确认。点击开始时会提示检索服务可能产生额外费用；可以继续，也可以取消联网后按现有上传文件继续。
6. 联网检索完成后会先显示候选文献、核心特征覆盖率、已覆盖和未覆盖特征。用户必须人工选定一份最接近现有技术，之后才开始新颖性、创造性及其他模块的正式审查。
7. 审查完成后可按主文本位置、重要程度或问题分类排列审查卡片，再逐条确认；只有“已采纳”的卡片会写入修订版批注。

四个模块分别使用独立的专业审查清单，并在一次请求中组合为连贯的审查任务。工具要求模型遍历全部权利要求及相关说明书内容、穷举有实质意义的不同问题，不采用固定的结论数量上限。

联网检索提供四种接入方式，所有密钥按服务分别保存，互不共享：

- 智谱 Web Search：预置官方 `web_search` 地址，填写 API Key 后即可使用，可选择搜索引擎和返回数量。
- 智慧芽 Patsnap MCP：预置智慧芽 Streamable HTTP MCP 地址，填写访问 Key 后加载 `tools/list`。用户可以勾选允许LLM使用的多个只读工具。
- EPO OPS：填写 EPO Consumer Key 和 Consumer Secret。工具内置与 `epo-ops-mcp` 核心工具同名同参数的适配器，包括 `ops_search`、书目、摘要、全文、同族、CPC检索及号码转换，无需额外安装 Python。
- 自定义 Streamable HTTP MCP：填写名称、服务器地址和可选的 Bearer Key，连接后读取服务器提供的工具；特殊鉴权还可以填写自定义请求头 JSON。可能修改外部数据的工具不会交给专利检索代理。

联网执行采用迭代式工具调用，而不是一次搜索：LLM先拆解技术特征并调用搜索工具，再根据命中结果改写检索式；对于高相关候选，继续调用摘要、书目、权利要求、说明书或同族工具核查。界面会显示每一步的工具名称和参数，并限制最大调用轮次及相同参数的重复次数。只有完成至少一次候选搜索和一次可用的详情核查后，检索代理才会整理结果。启用联网检索且当前服务凭证填写完整后，工具会自动加载可调用工具；“可调用工具设置”默认折叠，手动加载按钮保留用于失败重试。

辅助审查采用高召回覆盖式提示词：逐项拆解全部独立和从属权利要求，依次进行结构检查、跨文档对应检查、审查/无效/维权对抗性检查及最终遗漏复核。具有明确原文依据但证据仍不完整的合理风险会标记为“待人工核验”，同时禁止为了增加数量而重复报告或虚构问题。

外部检索返回的证据会注明服务来源。联网发现的文献统一标记为“候选对比文件”，必须人工核对公开日、全文和法律地位；未开启“补检潜在对比文件”时，只能用于技术事实核验，不能被当作新颖性或创造性的正式对比文件。

保存修订版时，工具会额外生成 `原文件名-LLM审查报告.xlsx`，记录全部审查卡片、原文位置、证据等级、来源、模型和规则库版本，以及用户是否采纳。

法律与审查实践部分使用内置的中国专利辅助审核规则库。当前内置版本会显示在 LLM 审查窗口中，并固定提示：辅助审查不构成法律意见，重要结论仍需由专利代理师或律师复核。

LLM 隐私边界：

- 默认不调用 LLM，也不上传正文。
- 每次审查都由用户明确选择服务商和发送范围。
- 权利要求内容只发送到用户选择的LLM，用于提取检索特征；MCP服务器仅接收LLM生成的工具参数，不接收整篇专利正文。
- 新颖性与创造性可依据用户上传文件、人工确认的联网候选文献，或二者共同分析；联网候选仍需人工复核公开日、全文和法律状态。
- API Key 仅在用户勾选保存时保存在本机。

## 专利整体评级

右侧批注区域下方提供整体评级：

- 技术理解评级：A/B/C/D
- 沟通评级：A/B/C/D
- 专利质量评级：A/B/C/D

保存修订版时，工具会额外生成一份 XLSX 评分留存文件，便于机构内部归档和复盘。

## 热加载新文档

顶部文件夹图标可用于重新选择文件。处理完一份文档后，不需要关闭工具，点击该图标即可打开另一份本地专利文件。

## 常见问题

### 为什么有些 PDF 无法读取？

如果 PDF 是空文件、下载未完成、加密文件，或不是可检索 PDF，工具可能无法读取。请确认文件已经完整下载，并且可以用普通 PDF 阅读器正常打开。

### 为什么附图标号识别不全？

附图 OCR 会受到线条密度、图像清晰度、扫描质量、标号字体、引出线干扰等影响。可以尝试：

- 使用更清晰的 DOCX/PDF。
- 切换 OCR 服务。
- 手动补充缺失标号。
- 删除少量误识别标号。

### 数字 0 会被当作标号吗？

默认不会。单独的数字 `0` 通常不是专利附图标号，工具会默认过滤。

### 工具会覆盖原文件吗？

不会。默认保存为 `-修订版` 文件。

### 云 OCR 会上传整篇专利吗？

不会。云 OCR 只上传附图图片用于识别标号。
